# Tip Calculator

## 💰 Calculate Tips & Split Bills Instantly

One-Page Website that calculates tips and splits bills between people instantly.

## ✨ Features

- ✅ **Instant Calculation** - Real-time updates as you type
- ✅ **Multiple Tip Options** - Quick buttons (5%, 10%, 15%, 18%, 20%, 25%)
- ✅ **Custom Tips** - Enter any percentage
- ✅ **Bill Splitting** - Split between multiple people
- ✅ **Fast Loading** - Loads in under 2 seconds
- ✅ **Mobile-Friendly** - Responsive design for all devices
- ✅ **No Registration** - Instant use, no signup required

## 📊 What It Calculates

| Metric | Description |
|--------|-------------|
| Tip Amount | Total tip based on percentage |
| Total | Bill + tip combined |
| Per Person | Individual share when splitting |

## 🛠️ Local Development

1. Clone repository
```bash

cd tip-calculator
```

2. Run local server
```bash
python3 -m http.server 8000
# or
npm run dev
```

3. Open browser
```
http://localhost:8000
```

## 🌐 Deployment (Vercel)

### Step 1: Push to GitHub

```bash
git init
git add .
git commit -m "Initial commit: Tip Calculator MVP"
git push origin main
```

### Step 2: Deploy to Vercel

1. Go to [vercel.com](https://vercel.com) and login
2. Click "Add New Project"
3. Select your GitHub repository
4. Vercel will detect it as a static site automatically
5. Click "Deploy"

Done! Your website is live on Vercel Free Plan.
